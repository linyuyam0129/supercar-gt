# 極速超跑 GT（手機網頁版）

用手機瀏覽器就能玩的 3D 賽車遊戲，純 HTML + JavaScript（[three.js](https://threejs.org/)），不需安裝、不需建置，直接放在 GitHub Pages 上。

## 特色

- **世界觀與聯賽園區**：故事發生在原創城市「曙光灣」，你是剛拿到「曙光灣極速聯賽」參賽證的新人車手。遊戲一開始就在園區裡，操控主角走動：
  - 1 號車庫：換車、換烤漆（技師小鈴）
  - 賽事報名處：選賽道、難度與對手人數（賽事總監老周）
  - 課金商店
  - 同期新人小葵會給賽道建議；衛冕冠軍「黑豹」凱只和「困難」等級的你比賽，對話會隨戰績改變
  - 車庫大樓上的戰績板記錄各賽道的勝利
- **電腦對手**：0 / 1 / 3 / 5 位對手，難度分簡單、普通、困難；對手會依彎道煞車、閃避超車。比賽中顯示即時名次，完賽有排名表，名次與難度影響金幣。只有你撞上前車才算碰撞失誤，被後車撞不算
- **10 台原創超跑**：車身比例與設計語言參考現實世界最快的極速超跑（低矮寬車身、大型進氣口、LED 燈條、碳纖維套件、巨型尾翼、長尾流線），但全部是原創造型，沒有使用任何真實品牌、車名或標誌。8 種烤漆
  - Aurora GT、Vento RS、Furia SF、Tempesta Hyper
  - Volta E-Hyper（四馬達純電）、Vortex GS（16 缸 GT 超跑）、Nordvind JX（巨型尾翼）、Corsa Lunga LR（長尾極速紀錄車，極速 455 km/h）
  - Kaze 85R（80 年代掀燈小跑車）、Saetta Classica（60 年代經典 GT）
- **6 條賽道**：
  - 綠野國際賽道（白天，寬敞好開）
  - 霧嶺山道（夜間山路，三連髮夾彎爬坡 + S 彎下坡，金幣 ×1.6）
  - 楓谷峠（秋季山谷，連續 S 彎與高低落差，金幣 ×1.4）
  - 夕陽海岸線（黃昏的懸崖海岸公路，翻越海岬山丘，金幣 ×1.5）
  - 雪峰隘口（雪地高山隘口，三個髮夾彎 + 高速下山，會下雪，金幣 ×1.8）
  - 沙漠極速環道（兩條超長直線，適合挑戰極速，金幣 ×1.2）
- **山路特色**：真實高低落差與坡度（上坡變慢、下坡加速）、窄路面、護欄與擋土牆、彎道箭頭牌、夜間車頭燈與反光片
- **賽道紀錄**：每條賽道保存最佳單圈
- **車庫展示間**：轉盤展示、可拖曳旋轉、換車換色
- **課金商店**：金幣包與 VIP 通行證（目前為測試模式，不會實際扣款）
- **比賽賺金幣**：完賽獎勵 + 無失誤圈加成，VIP 加倍
- **失誤才提醒**：偏離賽道、逆向、碰撞、打滑、錯過檢查點
- **三種提醒可切換**：震動（手機震動 / Xbox 控制器震動）、語音（中文語音合成）、畫面（橫幅 + 邊緣閃光）
- **操作**：觸控按鈕 / 滑動 / 重力感應、Xbox 控制器、鍵盤
- **五燈起跑**、3 段操控輔助、3 種鏡頭

## 操作方式

| 動作 | 手機 | Xbox 控制器 | 鍵盤 |
|---|---|---|---|
| 轉向 | ◀ ▶ 按鈕（可改滑動 / 重力感應） | 左搖桿 | A D / ← → |
| 油門 / 煞車 | 右下「油門」「煞車」 | RT / LT | W / S |
| 手煞車 | 「手煞車」 | A | Space |
| 重置車輛 | ↺ | Y | R |
| 切換視角 | 「視角」 | RB | C |
| 提醒開關 | 右上「震動 / 語音 / 畫面」 | 十字鍵 ← ↑ → | 1 / 2 / 3 |
| 暫停 / 設定 | ❚❚ | Start | Esc |

園區內：手機用左下拖曳走動、在畫面空白處左右滑動轉鏡頭、右下按鈕互動；鍵盤 WASD 走動、Q / E 轉鏡頭、Enter / F 互動；Xbox 左搖桿走動、右搖桿轉鏡頭、A 互動。

> iPhone 的 Safari 不支援網頁震動；重力感應第一次使用時會要求權限。建議在手機上「加入主畫面」以全螢幕遊玩。

## 發布到 GitHub Pages

1. 把這個資料夾的檔案推送到 GitHub 儲存庫（`main` 分支）
2. 到儲存庫 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/ (root)**，按 Save
3. 約 1 分鐘後網址會出現在同一頁：`https://<你的帳號>.github.io/<儲存庫名稱>/`

## 在 GitHub 網頁上直接修改

在儲存庫頁面按鍵盤 **`.`**（句點），會開啟 github.dev 網頁版編輯器，可以直接改程式並 Commit；Pages 會自動重新發布。

| 檔案 | 內容 |
|---|---|
| `js/data.js` | 車款規格、賽道定義、烤漆、商店商品、提醒文字 |
| `js/carModel.js` | 程序化車輛模型 |
| `js/carPhysics.js` | 賽車物理與操控輔助 |
| `js/track.js` | 賽道 / 山路、地形、護欄、建築、樹林 |
| `js/race.js` | 比賽流程、失誤偵測、提醒 |
| `js/garage.js` | 車庫展示間 |
| `js/main.js` | 畫面流程、選單、商店、劇情對話 |
| `js/hub.js` | 聯賽園區場景（可走動的主選單） |
| `js/character.js` | 程序化人物與動畫 |
| `js/story.js` | 世界觀、角色與對話 |
| `js/rivals.js` | 電腦對手 AI 與難易度 |
| `js/input.js` | 觸控 / 控制器 / 鍵盤 / 震動 |
| `js/audio.js` | 引擎聲、提示音、語音 |

## 關於課金

目前商店使用 `store.js` 裡的 `SimulatedProvider`（模擬付款），購買只會在本機增加金幣，**不會扣款**。
若要正式收費，需要接上真正的金流（例如 Stripe、綠界、Google Play Billing / Apple IAP），並由後端伺服器驗證付款後才發放金幣；GitHub Pages 只能放靜態網頁，無法單獨完成安全的付款驗證。
